# Обновление: Поддержка Физики с уровнями сложности

## Что изменилось

Добавлена поддержка предмета "Физика" с особой логикой генерации билетов на основе уровней сложности вместо стандартного деления на теорию/практику.

## Основные изменения

### 1. **types.ts**
- Добавлен предмет "Физика" в список SUBJECTS
- Добавлено поле `level?: number` для вопросов (используется только для физики)
- Добавлено поле `physics?: Question[]` в интерфейс Ticket
- Добавлена константа `PHYSICS_LEVELS = 5` (количество уровней сложности)

### 2. **generator.ts**
- Добавлена функция `generatePhysicsTicket()` для специальной логики физики
- Для физики выбирается по одному случайному вопросу из каждого уровня (1-5)
- Обновлена валидация для проверки наличия вопросов для каждого уровня

### 3. **BulkImport.tsx**
- При выборе предмета "Физика" вместо выбора "Теория/Практика" появляется выбор уровня (1-5)
- Вопросы для физики автоматически сохраняются с указанным уровнем

### 4. **Ticket.tsx**
- Билеты по физике отображают вопросы с указанием уровня сложности
- Формат: "Уровень 1: Вопрос..."
- Для остальных предметов сохранен стандартный формат (теория + практика)

### 5. **page-questions.tsx** (страница управления вопросами)
- Добавлен фильтр по уровням для физики
- Статистика показывает количество вопросов по уровням для физики
- В списке вопросов отображается уровень вместо типа для физики

## Как использовать

### Добавление вопросов по физике:

1. Перейдите на страницу "Управление вопросами"
2. В разделе "Массовое добавление":
   - Выберите предмет: **Физика**
   - Выберите уровень сложности (1-5)
   - Вставьте вопросы (по одному на строке)
   - Нажмите "Добавить все"
3. Повторите для каждого уровня

### Генерация билета по физике:

1. На главной странице выберите предмет **Физика**
2. Нажмите "Сгенерировать"
3. Билет будет содержать 5 вопросов (по одному из каждого уровня)

## Требования

Для генерации билета по физике необходимо:
- Минимум 1 вопрос для каждого уровня (всего 5 уровней)
- Если хотя бы для одного уровня нет вопросов, генерация будет невозможна

## Изменение количества уровней

Если нужно изменить количество уровней (например, сделать 10 вместо 5):
1. Откройте `types.ts`
2. Измените `export const PHYSICS_LEVELS = 5;` на нужное число
3. Все остальное будет работать автоматически

## Примеры вопросов для физики

**Уровень 1 (легкий):**
- Что такое сила?
- Определите понятие массы.

**Уровень 2:**
- Сформулируйте второй закон Ньютона.
- Что такое кинетическая энергия?

**Уровень 3 (средний):**
- Выведите формулу центростремительного ускорения.
- Объясните закон сохранения энергии.

**Уровень 4:**
- Решите задачу на движение тела под углом к горизонту.
- Рассчитайте момент инерции диска.

**Уровень 5 (сложный):**
- Докажите теорему Штейнера.
- Решите систему связанных тел на наклонной плоскости.
