# Генератор Экзаменационных Билетов

Веб-приложение для генерации экзаменационных билетов формата A6 landscape с реалистичным дизайном печатного документа.

## Возможности

- 📝 Генерация билетов с 2 теоретическими и 3 практическими вопросами
- 🎨 Реалистичный дизайн формата A6 (landscape)
- 💾 Хранение вопросов в localStorage браузера
- ⚡ Массовое добавление вопросов
- 📊 Статистика по предметам
- 🔄 Импорт/экспорт вопросов в JSON
- 🔍 Фильтрация и поиск вопросов
- 📋 Копирование билета в буфер обмена
- 🖨️ Поддержка печати

## Технологии

- Next.js 15
- React 19
- TypeScript
- Tailwind CSS

## Установка и запуск

### Требования
- Node.js 18+ 
- npm или yarn

### Шаги установки

1. **Распакуйте архив**
```bash
unzip exam-ticket-generator.zip
cd exam-ticket-generator
```

2. **Установите зависимости**
```bash
npm install
```

3. **Запустите в режиме разработки**
```bash
npm run dev
```

4. **Откройте в браузере**
```
http://localhost:3000
```

### Для production сборки

```bash
npm run build
npm start
```

## Использование

### Первый запуск

1. Откройте приложение в браузере
2. Перейдите на страницу "Управление вопросами"
3. Импортируйте seed-данные из файла `public/seed-questions.json` или добавьте вопросы вручную

### Добавление вопросов

**Массовое добавление:**
1. Перейдите в "Управление вопросами"
2. Выберите предмет и тип (теория/практика)
3. Вставьте вопросы в textarea (по одному на строке)
4. Нажмите "Добавить все"

**Импорт JSON:**
1. Подготовьте JSON-файл с массивом вопросов
2. Нажмите "Импорт JSON" и выберите файл

### Генерация билетов

1. На главной странице выберите предмет
2. Нажмите "Сгенерировать"
3. Используйте кнопки:
   - **Перегенерировать** — новый билет с другими вопросами
   - **Копировать билет** — скопировать текст в буфер обмена

### Печать билетов

1. Сгенерируйте билет
2. Нажмите Ctrl+P (или Cmd+P на Mac)
3. Установите формат A6 landscape в настройках печати

## Структура данных

### Формат вопроса
```json
{
  "id": "unique-id",
  "subject": "Математика",
  "type": "theory" | "practice",
  "text": "Текст вопроса",
  "tags": ["опционально"]
}
```

### Доступные предметы
- Математика
- Физика
- Информатика
- История
- Литература

Список предметов можно изменить в файле `lib/types.ts`

## Хранение данных

Все данные хранятся в localStorage браузера:
- `exam_questions` — список всех вопросов
- `exam_last_ticket_numbers` — последние номера билетов по предметам

**Важно:** Данные привязаны к браузеру и домену. При очистке кеша браузера данные будут удалены.

## Требования к вопросам

Для генерации билета по предмету необходимо минимум:
- 2 теоретических вопроса
- 3 практических задания

Если вопросов недостаточно, система выдаст соответствующее сообщение.
